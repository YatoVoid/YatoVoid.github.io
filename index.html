1 Work

  • Full Heartsweb · TypeScript, Next.js

    A Minecraft modpack builder that resolves dependencies, matches versions to the loader and checks the set against live Modrinth and CurseForge data before exporting one .mrpack. open · source

  • The Quiet Courierweb · Python, TypeScript, Next.js, Postgres

    A daily newspaper for Kindle and Kobo. One finished edition arrives at 5 a.m., laid out like an early-1900s broadsheet, and then it ends. It only uses licensed sources and carries no ads. sample · source

  • ForsakeAIbrowser · TypeScript, Svelte, WebGPU

    Marks the phrases that make text read as machine-written and rewrites them with a small model on your own graphics card. Every change can be undone, and numbers, names and links are left alone. open · source

  • lumenLinux · HolyC, OpenGL 3.3, GLSL

    A HolyC host for real-time fragment shader scenes, with an HDR bloom chain, hot reload and a deterministic offline renderer. Like the two entries after it, it is HolyC, Terry Davis's language, compiled to a native binary with hcc instead of running inside TempleOS. So far it has only been tested on Linux. notes · source

  • OssuaryLinux · HolyC, SDL2, OpenGL

    A first-person catacomb horror prototype. Find five relics, open the gate, get out before the warden finds you. Your lantern lets you see, and lets it see you. One level, no audio yet. download · docs · source

  • HolyC Graphics GuideLinux, macOS · HolyC, SDL2, OpenGL

    Thirteen example programs, from a software framebuffer and bitmap font to a scrolling platformer and OpenGL. Every example renders headlessly and CI checks each frame against a recorded hash. It also lists the hcc bugs I ran into, with workarounds. guide · source

  • Witch Atelierbrowser · JavaScript

    A spell circle drawing tool after Witch Hat Atelier. Freehand strokes are read by their shape, and a finished circle is checked against a spellbook. open · source

  • YatoVoid Music Boxbrowser · JavaScript, Web Audio

    An 8-bit music editor. Notes on a piano roll, a chord per bar, and playback with NES-style square and triangle waves. Exports WAV that loops without a click, MIDI, or a song file. open · source

  • Tankobondesktop · Python, Qt

    Packs downloaded manga chapters into one ordered .cbz per volume for Kindle Comic Converter, and places chapters that came without a volume number. Windows, macOS, Linux, and the AUR. download · source

  • Macro Tooldesktop · Python, Qt

    An auto clicker and macro recorder, including Wayland. Recordings come back as a few readable steps, and timing is measured against the clock so the rate holds for hours. download · source

  • Pekko FridgeAndroid · React Native

    An expiry tracker for food, medicine and cosmetics. Reads the printed date with the camera, on the phone, and reminds you before things go off. source

  • TLP Battery TunerLinux · shell

    One command for battery-focused TLP settings on any Linux distribution. Packaged for the AUR, .deb, .rpm and Homebrew. source

  • CRUNCH Burgersweb · client work

    A website rebuild for a Baku burger chain, in Azerbaijani, English and Russian. open

  • Schedule.azweb · TypeScript, Next.js, Postgres

    Booking and a directory for service businesses in Baku: barbers, salons, tutors, gyms. Staff calendars, SMS-confirmed bookings, and analytics from what was actually charged. open · source

  • YatoStreamself-hosted · Go

    A local anime and manga server: library scanning that copes with messy folder names, streaming, AniList sync and a manga reader, with desktop and mobile apps. source

  • Karaoke Queueself-hosted · JavaScript

    A song request queue for a local network, meant to replace paid per-song karaoke systems. Guests queue from a tablet and a second screen drives the speakers. source

  • Vitals Localbrowser · JavaScript

    Health reference and symptom triage. The question flow is built on published decision rules such as Wells, Alvarado and Ottawa, and red flags always win over scores. Works in 65 languages, translated on the device. open · source

2 WhaleTale

WhaleTale designs biometric, security, transport and infrastructure systems in Azerbaijan, from the PCB to deployment. I'm a co-founder and work on the electrical engineering. Some of what the company makes:

  • E-Gate, automated border control with biometrics and document checks
  • Think-ID, a mobile terminal for enrolling face, fingerprints and signature
  • Smart Bus and Bus Manager, a connected city bus and its media and passenger-count panels
  • Flight Controller, a flight controller board with its own sensors and autopilot
  • E-Padlock, a GPS cargo padlock opened by an encrypted NFC card
  • E-Bracelets, Fingerprint Controller, Smart Glasses and Residence Manager

Details are on whaletale.tech.
